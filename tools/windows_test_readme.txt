RALPH WOLF - VERSION DE PRUEBA PARA WINDOWS (64 BITS)

1. Descomprime TODO el ZIP en una carpeta.
2. Abre RalphWolf.exe. No necesitas instalar Godot.
3. Elige el idioma con las flechas y confirma con Enter o E.

Incluye el escenario, los niveles 00, 01, 02 y 03 y el laboratorio.
Los niveles 00 y 01 están abiertos desde el inicio. Desde el 02,
las puertas se desbloquean al completar el nivel anterior.
Para probar directamente cualquier nivel: F8 abre el laboratorio; acércate
a la puerta correspondiente y pulsa E. F8 desde el laboratorio vuelve al escenario.

CONTROLES
WASD / flechas: movimiento
Ratón: cámara
Espacio: salto / doble salto
Shift (pulsar repetidamente): carrera
Ctrl: sigilo
E: interacción / recoger
R: usar o colocar el objeto equipado
Tab y A/D: inventario
Escape: pausa, opciones, guardar y cargar
F5: cambiar idioma y regresar al mismo punto
F8: laboratorio
H: mostrar u ocultar la ayuda

Los guardados y la configuración son propios de cada usuario de Windows.
No se incluyen las partidas del desarrollador.
Ruta: %APPDATA%\Godot\app_userdata\Ralph Wolf - Sheep Raider Native

Es una versión en desarrollo: si encuentras un error, anota el nivel,
los pasos para reproducirlo y, si puedes, adjunta una captura.

El motor Godot y sus componentes: consulta Licencias_Godot.txt.
